Group-8-Appointment-Scheduling-System
The Health Service Appointment Scheduling System is a computerized application developed to simplify and improve the process of managing patient appointments in healthcare facilities. The system allows staff to create, view, edit, and delete appointment records while keeping all scheduling information organized in a centralized database.
Features (CRUD)

Create
-Add new appointments using the "New Appointment" form.
-Record the following information:
  -Client Name
  -Service
  -Phone Number
  -Appointment Date
  -Appointment Time
  -Status (Scheduled, Confirmed, Cancelled)
  -Notes

Read
-View all appointments in a table format.
-Search appointments by client name or service.
Filter appointments by status:
  - All
  -Scheduled
  -Confirmed
  -Cancelled

Update
  -Edit existing appointment records.
  -Modify appointment details, status, and notes.

Delete
  -Delete selected appointments.
  -Confirmation dialog prevents accidental deletion.

Additional Features
Appointment statistics dashboard:
  -Total Appointments
  -Today's Appointments
  -Upcoming Appointments
  -Color-coded appointment statuses. 
  -Scrollable appointment form.
  -Search functionality for quick record retrieval.

Instructions on How to Run the Appointment Scheduler System
Requirements:
  -You must have Python installed in your Laptop or Computer and open your preferred IDE(e.g Pycharm) that can run Python.
Then you can remove the login part and use this version:

  To run the program, download the project files and open the folder using PyCharm. Once the project is opened, you will see the system files in the Project Explorer panel on the left side.
  
  Locate the main.py file (or the main application file of the system) and run it by clicking the Run button at the top of PyCharm or by right-clicking the file and selecting Run.

  After running the program, the Appointment Scheduler System will open directly to the main interface.
The main interface allows users to manage appointments through the following features:
Add Appointment – Create a new appointment by clicking the New Appointment button and entering the client name, service, phone number, date, time, status, and notes.

View Appointments – Display all appointments in the appointment table.
Edit Appointment – Select an appointment and click Edit Selected to update its information.
Delete Appointment – Select an appointment and click Delete Selected to remove it from the system.
Search Appointments – Use the search bar to find appointments by client name or service.
Filter by Status – View appointments based on their status such as Scheduled, Confirmed, or Cancelled.
Dashboard Overview – Monitor the total number of appointments, today's appointments, and upcoming appointments displayed on the left panel.

All changes made within the system are automatically saved, ensuring that appointment records remain available for future use. The Appointment Scheduler System provides a simple and organized way to create, update, search, and manage appointments.
